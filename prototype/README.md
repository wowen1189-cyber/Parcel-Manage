# Prototype reference

The full clickable prototype lives on claude.ai as "Parcel Manage — Prototype" (screens: Manager app, Tenant portal, Vendor portal, Rental application, AI leasing agent).

- `LeasingAgent.dc.html` — source of the AI leasing agent screen. The `renderVals()` script at the bottom shows intended behavior (BYOK test gate, company settings, test-chat replies, screening decision rules). It is a design-tool format, not production code: rebuild it in the app's stack.
- `screenshots/` — Wesley adds screenshots of each prototype screen here. Match layout, spacing and colors to them, using `docs/06-design-system.md` tokens.

When a screenshot and a doc disagree, the doc wins; ask Wesley if it matters.
